## 🧩 Featured Project

### 🤖 Classify AI — Campus Intelligence Platform *(Flagship Project)*

A role-based campus management platform connecting attendance, academics, communication, and student support workflows into one secure desktop and mobile-ready system.

- 🎯 **Smart Attendance** — QR/token-based attendance with face verification and online/offline modes
- 👥 **Role-Based Dashboards** — dedicated workspaces for Admin, Assistant, Teacher, Student, and HOD
- 📊 **HOD Command Center** — timetable control, department pulse, and defaulter radar
- 📚 **Assignments & AI Tools** — grading, feedback, AI content analysis, and study predictor workflows
- 💬 **Campus Chat** — real-time messaging with groups, attachments, and read receipts
- 🖥️ Released as a **Windows Desktop app** (v2.4) with an **Android APK** testing build

**Tech:** Next.js, Tauri, Prisma, PostgreSQL (Neon), Socket.io / Pusher, Firebase, Cloudinary, face-api.js

🔗 **Website & downloads:** [classify-ai-app.vercel.app](https://classify-ai-app.vercel.app/)
